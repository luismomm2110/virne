PASSO 1: BASELINE (ALGORITMO FIXO)
================================================================================

Para cada objetivo, contamos quantas vezes cada algoritmo é o melhor:

EXEMPLO RAC:
  - Total de VNRs no teste: 617
  - ga_meta é o melhor em: 212 VNRs
  - Accuracy = 212/617 × 100 = 34.36%
  
  Interpretação: Se sempre usássemos ga_meta, acertaríamos em 34.36% dos casos.

EXEMPLO LRC:
  - pl_rank é o melhor em: 168 VNRs
  - Accuracy = 168/617 × 100 = 27.23%

EXEMPLO LAR:
  - ga_meta é o melhor em: 141 VNRs
  - Accuracy = 141/617 × 100 = 22.85%

================================================================================
PASSO 2: DYNAMIC SELECTION (TOP-3)
================================================================================

Para cada VNR, o modelo de árvore de decisão:
1. Gera probabilidades para cada algoritmo
2. Seleciona os 3 algoritmos com maior probabilidade (Top-3)
3. Verifica se o algoritmo verdadeiro (ground truth) está no Top-3

EXEMPLO RAC:
  - Modelo acerta (algoritmo verdadeiro está no Top-3): 545 VNRs
  - Accuracy = 545/617 × 100 = 88.33%

EXEMPLO LRC:
  - Modelo acerta: 527 VNRs
  - Accuracy = 527/617 × 100 = 85.41%

EXEMPLO LAR:
  - Modelo acerta: 500 VNRs
  - Accuracy = 500/617 × 100 = 81.04%

================================================================================
POR QUE TOP-3?
================================================================================

1. Mais realista: Operadores podem escolher entre múltiplas opções
2. Melhor performance: Top-3 accuracy (81-88%) >> Top-1 accuracy (~0%)
3. Tolerância a erros: Se o melhor algoritmo não estiver disponível, há alternativas
